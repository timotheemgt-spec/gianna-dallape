Copiée ✓ — colle-la dans Gmail
  1. Clique sur Copier la signature (ou sélectionne-la à la souris et fais Cmd/Ctrl + C).
  2. Dans Gmail : ⚙︎ Paramètres → Voir tous les paramètres → Général → Signature.
  3. Créer, donne-lui un nom, puis colle (Cmd/Ctrl + V) dans le cadre.
  4. Choisis-la comme signature par défaut pour les nouveaux emails et les réponses, puis Enregistrer les modifications en bas de page.

Gmail n'accepte que des polices standard : la signature reprend la mise en page et les couleurs du site avec des polices sûres (Arial Narrow, Georgia italique, Courier) pour s'afficher pareil chez tous les destinataires. La photo est hébergée sur giannadallape.com.
